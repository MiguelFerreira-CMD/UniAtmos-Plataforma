# Atmos — Conhecimento e Testes

O Atmos é o chatbot educacional da plataforma UniAtmos, desenvolvido para responder dúvidas sobre meteorologia e auxiliar os usuários na compreensão de fenômenos atmosféricos.

## Conhecimento do Chatbot

- Conceitos de meteorologia.
- Temperatura e sensação térmica.
- Umidade do ar e pressão atmosférica.
- Ventos, nuvens e precipitação.
- Interpretação de informações meteorológicas.

## Testes Realizados:

### Chatbot
- Testes de envio e recebimento de mensagens.
- Verificação da clareza e relevância das respostas.
- Testes de perguntas relacionadas à meteorologia.

### Site
- Testes de navegação e interface.
- Verificação do funcionamento do chat.
- Testes de interação entre o usuário e o Atmos.

### APIs
- Testes de comunicação com a API de inteligência artificial.
- Testes de consulta de dados meteorológicos.
- Verificação das respostas em caso de falhas nas APIs.

## Integrações

- **Groq API:** processamento das respostas de inteligência artificial, caso esteja configurada no backend.
- **Open-Meteo API:** consulta de informações meteorológicas.
- **Arduino:** integração para receber dados de sensores físicos.

## Observações

Os testes e as integrações devem ser atualizados conforme novas funcionalidades forem implementadas. O Atmos não deve inventar dados meteorológicos nem apresentar informações não verificadas como dados reais.
