# 🌤️ UniAtmos

> **Conheça o clima do Brasil através do Atmos.**

O **UniAtmos** é uma interface interativa de informações meteorológicas desenvolvida para apresentar dados e explicações sobre o clima de diferentes regiões e unidades do Brasil de forma simples, visual e amigável.

No centro da experiência está o **Atmos**, um robô virtual que interage com o usuário através de um chatbot e responde perguntas relacionadas à meteorologia e ao clima.

---

## 🤖 Atmos

O **Atmos** é o robô responsável pela interação com o usuário.

Possui um **chatbot integrado**, permitindo que o usuário converse e faça perguntas relacionadas ao clima.

O Atmos possui uma característica visual dinâmica: **sua cabeça muda de acordo com o horário do dia**, tornando a interface mais viva e adaptada ao momento em que o usuário está acessando o UniAtmos.

### 🕐 Comportamento visual

A aparência do Atmos pode variar de acordo com o período:

* 🌅 Manhã
* ☀️ Tarde
* 🌙 Noite

Dessa forma, a interface acompanha o horário atual e adapta a aparência do robô.

---

## 💬 Chatbot Meteorológico

O chatbot do UniAtmos é focado exclusivamente em assuntos relacionados à **meteorologia e condições climáticas**.

O usuário pode conversar com o Atmos para obter explicações e informações sobre temas como:

* 🌡️ Temperatura
* 🌧️ Chuva
* 💨 Ventos
* 💧 Umidade
* ☁️ Condições do céu
* 🌞 Previsões e condições climáticas
* 🌎 Clima de diferentes regiões do Brasil
* 📍 Informações meteorológicas por unidade federativa

Além das respostas relacionadas ao clima, o Atmos possui **respostas configuradas para situações específicas**, garantindo uma experiência mais controlada e consistente em determinados casos.

---

## 🇧🇷 Meteorologia no Brasil

O UniAtmos foi desenvolvido com foco no território brasileiro.

A interface permite consultar informações meteorológicas de diferentes **unidades da UNIP** espalhadas pelo Brasil, possibilitando visualizar as condições climáticas de cada região onde a instituição possui unidades.


O projeto busca transformar informações meteorológicas em uma experiência mais fácil de compreender, utilizando uma interface visual e um assistente virtual.

---

## 🖥️ Interface

A interface do UniAtmos foi desenvolvida para ser simples, moderna e interativa.

### Navbar

O projeto possui uma barra de navegação com acesso a diferentes áreas:

* **Ajuda**
* **Sobre**
* **Créditos**

### Chat

O chatbot ocupa uma área central da interface, permitindo que o usuário envie mensagens e receba respostas do Atmos.

### Footer

O projeto também possui um **footer** com informações complementares sobre o UniAtmos.

## 🏗️ Tecnologias

### Frontend

O frontend foi desenvolvido utilizando:

* **React**
* **TypeScript**
* **Vite**
* **HTML5**
* **CSS**

### Backend

O backend utiliza:

* **Python**
