# UniAtmos — Frontend

Interface web do UniAtmos, uma plataforma de meteorologia com o chatbot Atmos.

## Tecnologias

- React
- TypeScript
- Vite
- HTML
- CSS

## Executar o projeto

Na pasta principal do projeto, execute:

```bash
npm install
npm run dev
```

O frontend estará disponível no endereço indicado pelo Vite, normalmente `http://localhost:3000`.

## Funcionalidades

- Interface do chatbot Atmos.
- Consulta de informações meteorológicas.
- Interação com o usuário.
- Interface adaptável e interativa.
